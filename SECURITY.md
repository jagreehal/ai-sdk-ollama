# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

- Email **jag.reehal+security@gmail.com**, or
- use GitHub's private vulnerability reporting: [Security → Report a vulnerability](https://github.com/jagreehal/ai-sdk-ollama/security/advisories/new).

Include the affected version, a minimal reproducer (a unit test with a mocked Ollama client is ideal), and the impact you expect. You should get a reply within 7 days.

## Supported versions

Fixes go into the latest published version. Older versions do not get backports.

## Scope

[`.oss-scanner/threat_model.md`](.oss-scanner/threat_model.md) describes what we treat as untrusted input and how we rate severity.
